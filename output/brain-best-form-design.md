# SAMURAI脳（/brain）最高形デザイン — 一級品リサーチ統合版
2026-06-21 ／ 出典: Crayon・Klue・Kompyte・Contify・AlphaSense・CB Insights・SimilarWeb（競合インテリジェンス）／ Artifact・Particle・Feedly・Perplexity Discover・tldr・Morning Brew・Stratechery・The Information・SmartBrief（ニュースブリーフ）／ Notion・Tana・Reflect・Mem・Perplexity・Claude・ChatGPT・Linear・Vercel・Raycast・Superhuman・Arc（セカンドブレイン＋UI）

## 一級品が"全部やってる"8法則（＝最高形の土台）

1. **開いた瞬間に価値（空欄禁止）** — ホームは自己更新する集約面。今日の新着・直近の続き・関連を常に表示。（Crayon Daily Digest / Notion Home / Linear Inbox+Triage / Reflect daily note）
2. **全部読ませない** — 重要度で上位だけ出し、密度を逓減（重要は長く・他は箇条書き）。（Crayon Importance Score / Morning Brew / tldr）
3. **要約には必ず出典**（主張の"真隣"にインライン番号引用＋favicon付きソースカード、ホバーで原文スニペット）— AI要約の信頼はこれで初めて立つ。出典なし要約は載せない。（Perplexity / AlphaSense / CB Insights / Google AI Overviews）
4. **事実 → なぜ重要 → 次の一手 を1セットで** — 情報で終わらせず行動に繋ぐ。（Stratechery / The Information / Crayon Enable）
5. **差分だけ（前回以降の新着）＋色でglance** — 全文でなく"変わった所"。重要/温度感を色で瞬間把握。（Kompyte diff / Feedly 緑優先・青要約）
6. **制約で美しく** — 本文1書体＋数値Mono／アクセント1色だけ／グレー階調に役割固定／狭い中央カラム＋広い余白。（Notion 3書体 / Reflect 変更不可 / Linear LCH / Vercel Geist「インクがブランド」）
7. **回答 → 次へ** — フォロー質問チップ（控えめ・消せる）＋ワンクリック行動。AIは「聞く→深掘り→書き戻す」で初めて差別化。（Perplexity pill / Tana Command Nodes / Mem Agentic）
8. **Cmd-Kパレットを背骨に** — キーボードで作成・検索・移動・AI実行が完結。検索が空でも入力を質問にfallback＝行き止まりなし。（Linear G-prefix / Raycast fallback / Superhuman / Arc）
- ＋**競合はバトルカード（1社1枚・30秒スキャン）** — 概要/勝ち筋3/価格/反論対応(相手の言葉で)/**言ってはいけない地雷**/更新ログ。SAMURAIの「中央値で正直」と地雷リストは相性抜群。（Crayon / Klue 標準8セクション）

## /brain の最高形（この8法則を全部のせ）

### タブ構成：**今日** ／ 🧠兄さん ／ 🐣キャッチアップ ／ ⚔️競合
（「今日」を新設し既定タブに）

### ① 「今日」タブ＝朝の司令塔（空欄禁止）
- 挨拶＋日付。
- **⚡今日の3つ**：重要度上位3件だけ。各カード＝〔重要度●〕**見出し** ／ 何が起きた（1〜2文・事実）／ **なぜ重要**（1文・自社文脈、色帯で強調）／ 出典チップ（favicon＋媒体名、複数なら横並び＝クロスチェック）／ **[🧠深掘り] [✍️ネタにする]**。
- **続き**：直近の会話（昨日の続きを1タップ再開）。
- 「全部見る」で🐣キャッチアップへ。新着ゼロの日は直近スレ/保存質問を出す（空欄を作らない）。

### ② 🧠兄さん（チャット）— 既存のChatGPT/Claude風に3upgrade
- **出典インライン＋ソースカード**：URLを読んだ/根拠がある主張に番号、下にfavicon＋媒体＋1行スニペット。
- **フォロー質問チップ×3**：回答末尾に「根拠は？」「競合は？」「うちのLPに落とすと？」（控えめ・消せる）。
- **ワンクリック行動**：「✍️ネタにする」「💾outputに保存」「📋Slack下書き」。

### ③ 🐣キャッチアップ — 既存＋
- 各カードに「**なぜあなたに出したか**」タグ（例：ウォッチ"中小工務店"にマッチ）。
- 重複は1イベント1カードに統合＋出典チップ横並び。
- ⚡30秒要約・NEWバッジ（実装済）。

### ④ ⚔️競合（新）— バトルカード
- Rendery系/ステージング系/企画系…の主要競合を1社1枚。30秒で「どう勝つか」が出る。**反論対応は相手の言い回しで＋2文で旋回**、**言ってはいけない地雷**（誇張＝失注地雷）を明示。キャッチアップで競合の新着が出たらカードの更新ログに溜まる。

### ⑤ 全体の質感（法則6・8）
- 本文1書体＋数値Mono。アクセント1色（兄さんの発言/主要CTAだけ）。グレー6〜8段に役割固定。中央カラム狭め＋広い余白。
- **Cmd-K**：質問/過去スレ検索/タブ移動/URLを兄さんに読ませる/output。`G`系でタブ瞬間移動。
